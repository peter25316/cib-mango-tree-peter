#
# Issue 2: Datetime Comparison Errors in Pipeline
# -----------------------------------------------
# Symptom: TypeError when running unified_pipeline.py
# Message: "Cannot compare tz-naive and tz-aware datetime"
# Location: Before coordination analysis (lines ~150-200)
# Cause: Mixed timezone-aware/naive datetimes from pandas >=2.0
# Solution: Add .dt.tz_localize(None) to normalize timestamps
# Example Fix:
#   df['post_timestamp'] = pd.to_datetime(df['created_at']).dt.tz_localize(None)
#

# Cause: API change in polars 1.0+
