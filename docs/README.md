# Documentation

This folder contains detailed explanations of the methodologies and algorithms used in the CIB Mango Tree project.

## Contents

### Methodology Explanations

- **[COORDINATION_DETECTION_EXPLAINED.md](COORDINATION_DETECTION_EXPLAINED.md)** - Complete methodology for detecting coordinated accounts through content similarity, hashtag patterns, retweet amplification, and temporal synchronization

- **[KLEINBERG_ALGORITHM_EXPLAINED.md](KLEINBERG_ALGORITHM_EXPLAINED.md)** - Detailed explanation of Kleinberg's burst detection algorithm used to identify periods of elevated posting activity

- **[TEMPORAL_CLUSTERING_EXPLAINED.md](TEMPORAL_CLUSTERING_EXPLAINED.md)** - Alternative methodology using K-means clustering on temporal features to identify behavioral patterns (not used in production due to limitations)

### Network Analysis

- **[NETWORK_ANALYSIS_CONCEPTS.md](NETWORK_ANALYSIS_CONCEPTS.md)** - Network metrics (density, clustering, centrality, modularity) and structure classification (hierarchical, distributed, mixed)

- **[NETWORK_EDGE_ANALYSIS.md](NETWORK_EDGE_ANALYSIS.md)** - Coordination edge analysis and network construction methodology
